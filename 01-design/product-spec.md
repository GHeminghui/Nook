## 1. 产品定位

**Nook —— 面向教师的 iPad 本地教学资料库 App。**

用「**真实文件夹 + 标签**」双层模型，一个 App 解决三件事：

1. **多维归类**：文件夹（含子文件夹）承载主归类，标签承载跨文件夹的多维属性。
2. **快速检索**：文件名 + 全文（PDF/HTML 正文）+ 标签组合筛选。
3. **顺畅查看与分发**：PDF/图片/单文件 HTML 预览，系统分享与打印。

## 2. 目标用户与场景

- **用户**：非技术型教师，以 iPad 为主要设备，日常高频备课。
- **核心场景**：
  - 备课时从历史资料中快速找回某份讲义/习题。
  - 同一份资料按班级/版本区分。
  - 收录 AI 生成的单文件 HTML 资料并直接查看。
  - 把资料发给学生（系统分享）或打印成纸质。

## 3. 范围

### 3.1 v1 范围（in scope）

| 编号 | 模块 | 内容 |
|------|------|------|
| FR-1 | 资料导入 | 从「文件」多选导入；支持 PDF / 图片 / HTML / 其他格式 |
| FR-2 | 文件夹管理 | 新建 / 重命名 / 移动 / 删除；**支持多级子文件夹** |
| FR-3 | 资料管理 | 浏览 / 多选 / 移动 / 重命名 / 复制 / 删除 |
| FR-4 | 标签体系 | 标签创建 / 重命名 / 删除；一份资料可打**多个**标签 |
| FR-5 | 检索 | 文件名 + 全文（PDF/HTML 正文）+ 标签组合；可与文件夹范围叠加 |
| FR-6 | 预览 | PDF（翻页/缩放）、图片、**单文件 HTML（WebView 渲染）** |
| FR-7 | 分享与打印 | 系统分享面板（微信/QQ/AirDrop/存储到文件）+ 系统打印 |

### 3.2 不在 v1 范围（out of scope）

手写批注、Mac 客户端、扫描件 OCR、AI 辅助命名与摘要、微信开放平台深度一键分享、版本历史/回收站高级策略。

## 4. 功能需求与交互

### FR-1 资料导入
- 入口：资料库页「导入」按钮。
- 交互：唤起系统文件选择器 → 可多选 → 选择目标文件夹 →（可选）批量打标签 → 确认 → 显示导入进度。
- 规则：同名文件自动追加序号 `(1)`；导入失败不残留半成品；导入完成后异步建立全文索引。

### FR-2 文件夹管理
- 支持**任意多级**子文件夹（建议使用层数 ≤5，界面不限制）。
- 操作：新建、重命名、移动（改变父级）、删除（二次确认，级联处理）。
- 文件夹树在侧栏可展开/折叠；磁盘上对应真实目录。

### FR-3 资料管理
- 列表/网格视图；支持多选。
- 操作：移动、重命名、复制、删除（二次确认）。
- 排序：名称 / 导入时间 / 修改时间 / 大小 / 类型。

### FR-4 标签体系
- 全局标签库；标签可设置颜色。
- 一份资料可绑定**多个**标签；标签可重命名、删除（删除仅解除关联，不删资料）。
- 标签用于检索筛选，与文件夹范围**叠加**。

### FR-5 检索
- 顶部搜索框输入关键词 → 命中**文件名 + 正文**（PDF 抽取文本、HTML 去标签文本）。
- 范围限定：可勾选"仅当前文件夹"。
- 标签筛选：可多选标签，支持"**满足任一 / 同时满足**"切换。
- 结果高亮关键词；点击进入预览。

### FR-6 预览
- PDF：翻页、缩放、跳页。
- 图片：缩放、平移、多图左右滑动。
- HTML：用内置 WebView **渲染成页面**；若引用了外部资源，提示"部分资源可能无法显示"。
- 其他类型：使用系统 QuickLook 通用预览。

### FR-7 分享与打印
- 预览页/列表长按 → 系统分享面板（微信/QQ/AirDrop/存储到文件）。
- 支持系统打印（选择打印机/份数）。
- **说明**：微信/QQ 走系统分享面板，**无需任何申请**。

### FR-8 系统分享扩展
- 在其他 App 分享文件/图片/URL/文本 → 选「存入 Nook」→ 选择目标文件夹 + 标签 → 保存。
- 扩展与主 App 共享同一资料库。

### FR-9 iCloud 备份与同步
- 资料库目录位于 App 的 iCloud 容器，文件与元数据一并同步。
- 多设备登录同一 Apple ID 即可看到一致内容。
- 冲突策略：后写覆盖 + 提示（版本历史留后续）。

## 5. 关键流程

**流程 A：找资料**
打开 App →（选文件夹 / 输入关键词 / 勾选标签）→ 结果列表 → 点开预览 → 分享或打印。

**流程 B：收资料**
其他 App 分享 → 「存入 Nook」→ 选文件夹 + 标签 → 完成。

**流程 C：整理**
进入文件夹 → 多选资料 → 移动 / 打标签 / 重命名 / 删除。

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 易用性 | 高频操作 ≤2 步完成；界面面向非技术用户 |
| 性能 | 千级资料下列表滚动流畅；搜索 1 秒内返回；导入大文件有进度且不卡界面 |
| 离线 | 完全离线可用（本地库） |
| 隐私 | 数据默认存本地；iCloud 仅为用户自有 Apple ID 的私有同步 |
| 兼容 | iPadOS 17 及以上 |

## 7. 边界与错误处理

- 大文件导入：进度提示、可取消、失败回滚。
- 重名：自动追加序号。
- 删除文件夹：二次确认 + 级联处理。
- 不支持的格式：允许存入，按"其他"类型通用预览。
- HTML 外部资源失效：明确提示。
- 同步冲突：后写覆盖 + 提示。
- 存储不足：导入前检查并提示。

## 8. 验收标准（v1 Definition of Done）

- [ ] 能导入 PDF/图片/HTML，并落入指定子文件夹
- [ ] 能建立多级子文件夹并移动资料
- [ ] 能给资料打多个标签，并按"文件夹范围 + 标签 + 关键词"组合筛选
- [ ] 能按**文件名与正文关键词**检索到结果
- [ ] 能正确预览 PDF/图片，**HTML 渲染成页面**
- [ ] 能从**系统分享面板**分享，能**打印**
- [ ] 能从其他 App 通过**分享扩展**存入资料
- [ ] **iCloud 备份/同步**在多设备生效
- [ ] 全部自动化测试**真实运行通过**（非仅存在测试文件）
