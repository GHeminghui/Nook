支持与帮助

适用于 iPadOS 17 及以上版本

快速开始
  1. 打开 App，点右上角「导入」，从「文件」中选择 PDF、图片或 HTML。
  2. 在左侧新建文件夹，把资料移动进去；一份资料可以打多个标签。
  3. 在搜索框输入文件名或正文关键词，也可以点标签筛选。
  4. 点 PDF 会用系统预览打开，右上角标记按钮可手写、加形状和签名。

常见问题

为什么有些 PDF 搜不到内容？

正文检索依赖 PDF 里的文字层。扫描件或图片型 PDF 没有文字层，暂不支持 OCR，因此搜不到；可以先用支持 OCR 的工具转换后再导入。

iCloud 没有同步怎么办？

先确认「设置 → Apple ID → iCloud → iCloud Drive」已开启，并允许本 App 使用 iCloud；再确认设备已联网。若仍未同步，可在「文件」App 中查看 Nook 文件夹是否存在对应文件。没有登录 iCloud 时，资料只保存在本机。

资料存在哪里？会丢吗？

资料以真实文件保存在 App 的 Documents 目录，可在「文件」App 的「我的 iPad → Nook」中查看。建议开启 iCloud 或定期把重要文件另存一份。

为什么网页课件里的图片不显示？

HTML 引用了外部网络资源时，离线或资源失效会导致部分内容无法显示。把资源一起放到同目录、使用相对路径，可以避免这个问题。

分享扩展找不到 Nook？

在分享面板中向左滑动「更多」，打开「Nook」开关；如果没有出现在列表里，重启设备后再试。

删除文件夹会删掉里面的文件吗？

文件夹内（含子文件夹）还有文件时，App 会阻止删除；清空后删除文件夹不会影响其他位置的文件。

Support

For iPadOS 17 and later

Quick start

  1. Open the app and tap Import (top right); pick PDFs, images or HTML from Files.
  2. Create folders in the sidebar, move items in, and add multiple tags.
  3. Search by file name or content, or tap a tag chip to filter.
  4. Tap a PDF to open the system preview; use the markup button to handwrite, add shapes or sign.

FAQ

Why can't some PDFs be found by search?

Full-text search relies on a text layer. Scanned or image-only PDFs have none; OCR is not supported yet.

iCloud is not syncing

Check that iCloud Drive is enabled in Settings, that the app is allowed to use iCloud, and that the device is online. Without iCloud, data stays on the device.

Where are my files?

They are stored as real documents in the app's Documents folder, visible in Files under “On My iPad → Nook”. Keep iCloud on or export important files as a backup.

Images in an HTML slide are missing

Pages that reference external resources may render partially offline. Keep assets next to the HTML file and use relative paths.

Nook is missing from the share sheet

Swipe left in the share sheet, tap More, and enable Nook. Restart the device if it still does not appear.

Does deleting a folder delete its files?

Deleting is blocked while a folder (or any subfolder) still contains files. Once empty, deleting the folder does not affect files elsewhere.
