# 设备边框来源

本目录的 `apple-ipad-pro-m5-13-landscape.png` 来自 **Apple 官方 Apple Design Resources**：

- 页面：https://developer.apple.com/design/resources/#product-bezels
- 文件：`Bezel-iPad-Pro-(M5).dmg` → `PNG/iPad Pro (M5) 13" - Space Black - Landscape.png`
- 规格：3000 × 2300，带 alpha；屏幕透明区正好是 2752 × 2064（iPad 13 英寸横屏截图尺寸）

使用时须遵守同目录 `apple-design-resources-license.rtf`（Apple Design Resources License）。这些边框仅用于 App 界面展示/营销素材，不要单独再分发。

旧的手绘 CSS 边框与第三方模板已移除。
