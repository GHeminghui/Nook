在 iPad 上导入
  1. 点上面的「下载全部」，Safari 会存到「文件」App 的「下载」。
  2. 打开「文件」App → 下载 → 长按 samples.zip → 解压。
  3. 打开知栈 / KnowStack → 右上角「导入 / Import」→ 选三个文件。
  4. 如果只想单独下载，点下面的 PDF / HTML / PNG 按钮。

录屏时建议把三个文件都导入，分别展示 PDF 标注、HTML 渲染和图片预览。文件内容为英文，方便审核员阅读。
