Nook / KnowStack review samples
--------------------------------
sample-functions.pdf   A one-page study note with a text layer (good for search).
sample-web-slide.html  A single-file web slide (open it in the app).
sample-image.png       A rendered page image (good for image preview).

How to test:
1. Unzip this folder and put the files in Files (On My iPad).
2. Launch KnowStack, tap Import (top right), select all three files.
3. Create a folder and a tag, then search for "functions".
4. Tap the PDF to open the system preview and try markup.
