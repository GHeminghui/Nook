## 描述（4000 字符以内）

```
知栈是一款为老师和学生准备的本地资料管理工具。课件、试卷、错题、作文素材和网页课件，不必再散落在聊天记录、网盘和相册里。

■ 高效分类
用多级文件夹整理资料：新建、重命名、移动、删除，也可以直接拖拽调整顺序。文件夹和资料都以真实文件保存，结构和你电脑上的习惯一致。

■ 标签与搜索
一份资料可以打多个标签，按「文件夹范围 + 标签 + 关键词」组合筛选。支持文件名与 PDF / HTML 正文检索，输入关键词就能定位到具体内容。

■ 打开就能看
PDF、图片、网页课件直接在 App 内预览。PDF 可调用系统预览做手写、形状、签名等标注，保存后立即生效；网页课件用 WebView 渲染，公式、表格、排版都能正常显示。

■ 收资料不用绕路
从「文件」App 多选导入，或通过系统分享面板把其他 App 里的文件直接存进来；支持打印，也能再次分享出去。

■ 数据在自己手里
资料存放在 App 的 Documents 中，可在「文件」App 的知栈文件夹里直接查看和管理；登录 iCloud 后，文件会随 iCloud Drive 在多台设备间同步。没有账号系统、没有广告、没有第三方统计 SDK。

■ 中英文界面
界面跟随系统语言，支持简体中文与 English。

适合：
· 老师备课：按学科 / 年级 / 章节归档课件、试卷、教案
· 学生整理：错题本、笔记、作文素材、听力原文
· 家长留存：家长会材料、成绩单、活动通知

说明：
· 扫描版 PDF 暂不支持 OCR，图片型 PDF 无法通过正文搜索到
· HTML 若引用外部网络资源，离线时部分内容可能无法显示
· 需要 iPadOS 17 或更高版本
```

## 审核备注（App Review Notes）

```
App 为 iPad 专用，无需登录，也没有演示账号。

测试路径：
1. 启动后是「全部资料」列表，右上角「导入」可从「文件」选择 PDF / 图片 / HTML；
2. 长按资料可重命名、编辑标签、移动到其他文件夹、删除；
3. 点击 PDF 会打开系统预览，右上角标记按钮可手写 / 形状 / 签名；
4. 点击 HTML 会在 App 内渲染网页；
5. 侧栏可新建文件夹与标签，支持多级嵌套。

App 不含账号、广告、内购或第三方分析 SDK。iCloud 同步需要设备登录 iCloud 后才会启用；未登录时数据仅保存在本机。
```
